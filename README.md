## ⚡ SYSTEM OVERVIEW

**MHD-Quran** adalah antarmuka web Al-Qur'an modern berstandar tinggi yang dibangun dengan estetika *cyberpunk / hacker*. Menggabungkan presisi teks suci Al-Qur'an dengan kecepatan penuh arsitektur modern berbasis Vite dan TypeScript, tanpa mengorbankan performa maupun kenyamanan visual.

---

## 🛠️ CYBER STACK (TECHNOLOGY)

* **Core Engine:** React 19 + TypeScript (`.tsx`)
* **Bundler / Compiler:** Vite (Ultra-fast HMR & Build)
* **Styling Matrix:** Custom Neon CSS & Tailwind-inspired Cyber Design (`#00ff66` Neon Glow)
* **Data Source:** Dynamic REST API (Real-time fetching)
* **Deployment Network:** Cloudflare Pages Edge Network

---

## 🚀 CORE FEATURES

* **[x] Neon Cyberpunk Theme:** Tampilan gelap gulita (`#0a0a0a`) dengan aksen hijau neon khas terminal elit (`#00ff66`).
* **[x] Multi-Language Support:** Pilihan terjemahan dalam berbagai bahasa secara dinamis.
* **[x] Real-time API Integration:** Mengambil data surat dan ayat langsung dari server publik secara instan tanpa membebani penyimpanan lokal.
* **[x] Responsive & Lightweight:** Dioptimalkan untuk kecepatan akses tinggi di berbagai perangkat (Mobile & Desktop).
* **[x] Clean Modular Architecture:** Struktur komponen yang terisolasi dengan rapi (`components/`, `api.ts`, `types.ts`).

## ⚙️ LOCAL DEPLOYMENT GUIDE

Ikuti protokol di bawah ini untuk menginisiasi sistem secara lokal di mesin Anda:

1. **Clone Repository**
   ```bash
   git clone https://github.com/muslim-hacker-division/mhd-quran.git
   cd mhd-quran
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```
